# Birthday scratch-card landing

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8080 --directory birthday-portaventura
```

После этого страница будет доступна по адресу `http://localhost:8080`.

Тексты находятся в `index.html`, стили — в `styles.css`, логика скретч-слоя — в `script.js`.
